# __PROJECT_NAME__

Production-oriented SaaS starter generated by `create-saas-stack`.

## Quick start

1. Copy `.env.example` to `.env` at the repository root and fill values.
2. `pnpm install`
3. `pnpm dev`
4. In another terminal, `pnpm worker`

> Important: Clerk requires `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` for the browser and `CLERK_SECRET_KEY` for server routes. Keep both in the root `.env`.

## Webhooks

- Stripe webhook: `/api/stripe/webhook`
- Clerk webhook: `/api/clerk/webhook`

Use Stripe CLI for local forwarding:

```bash
stripe listen --forward-to localhost:3000/api/stripe/webhook
```

## Providers

- Clerk: email-first auth, orgs and memberships
- Stripe: hosted checkout + webhooks as source of truth
- Loops: event delivery through worker queue
- Supabase: Postgres + Storage signed uploads
